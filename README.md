Horizon Rise is a Unity-based PC game developed as both a college project and a portfolio showcase, focusing on performance, responsiveness, and system-aware optimization.

Built using Unity 6000.3.1f1, the project demonstrates practical game development skills such as graphics scaling, background loading, and PC optimization.

**🖥️ How to Play**

**Step 1:**
Download the project build

**Step 2:**
Unzip the downloaded file

**Step 3:**
Run Horizon Rise.exe


Enjoy the game 🎮

**✨ Key Features**

**🔧 Auto Graphics & Frame Rate Configuration**

1. Automatically detects VRAM size and graphics driver
2. Adjusts graphics quality and frame rate for optimal performance
3. Ensures smooth gameplay across low-end to high-end systems

**🚀 Background Scene Loading**

1. All scenes are loaded in the background
2. Reduces loading delays
3. Provides a smooth and responsive gameplay experience

**⚡ Performance-Oriented Design**

1. Highly optimized for Windows PCs and laptops

**🛠️ Built With**

1. Engine: Unity 6000.3.1f1
2. Platform: Windows
3. Focus Areas: Optimization, performance scaling, scene management
